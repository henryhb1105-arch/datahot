企业团队的 Cowork 与插件

管理员现在可以创建私有插件市场，更好地控制插件、连接器和技能。我们还在更多部门增加了新的插件和连接器。

  • 类别代理企业 AI
  • 产品Claude Enterprise
  • 日期：2026年2月24日
  • 阅读时间：5分钟
  • 分享复制链接https://claude.com/blog/cowork-plugins-across-enterprise

今天，我们宣布推出 Cowork 和插件的更新 帮助企业将 Claude 定制为符合您工作方式。插件将 Claude 转变为每个角色和部门的专业代理。现在，您可以构建私有市场，在整个组织中分发它们。

本次发布还使插件更易于构建和定制，赋予管理员对市场和连接器更多的控制权，并在更广泛的职位中增加新的插件和连接器。Claude 现在还可以跨 Excel 和 PowerPoint 进行编排，端到端地工作并在应用之间传递上下文。

‍

Silvern Capital 是一家虚构公司。演示中的大多数团队在 Cowork 中工作，而法务团队则在汤森路透 CoCounsel Legal 中工作——这是一个使用 Claude Agent SDK 从头构建的专门法律代理。

升级插件体验

今天，我们推出了一系列更新，使在整个组织中创建、使用和管理插件更加容易。

管理员现在可以从 Starter 模板设置插件或从头构建，Claude 会通过提问来引导您完成设置，以定制技能、命令和连接器（MCP）以适应您的公司。所有这些都集中在一个新的统一菜单“自定义”中，该菜单整合了插件、技能和连接器，使管理员可以在一个地方查看和管理所有内容。

连接器体验也经过了彻底改造，改进了目录、简化了管理控制，并更易于管理哪些连接器捆绑在插件中。管理员还对团队可以访问的插件拥有更多控制权，包括特定于组织的市场、作为插件源的私有 GitHub 仓库（私有测试版）、按用户配置和自动安装。

在用户方面，斜杠命令现在以结构化表单启动，因此运行诸如“生成报告”或“仪表板”之类的工作流程感觉像填写简报一样直观。Cowork 现在在整个过程中都包含公司品牌，包括为您的组织量身定制的重新设计的首页体验。

此外，我们正在添加OpenTelemetry支持，让管理员能够跟踪其团队的使用情况、成本和工具活动。

新的连接器和插件

当连接到您已经在使用的工具时，Cowork 最能处理复杂的任务。连接器使 Claude 更接近您的工作所在之处——帮助您跨工具更快地移动，而不是替代您依赖的专业知识或软件。

现在可以使用来自流行企业软件提供商的新连接器，包括 Google Workspace（日历， 云端硬盘， Gmail）、DocuSign、Apollo、Clay、Outreach、Similarweb、MSCI、LegalZoom、FactSet、WordPress以及Harvey。像Salesforce 的 Slack、LSEG、标普全球、Apollo、Common Room和 Tribe AI（见下文）等公司也构建了插件供联合客户探索。

我们还在扩展预构建插件模板库，以便更多知识工作者在 Cowork 中找到价值。每个模板都是与相关领域的从业者共同设计的，因此工作流程、术语和输出反映了实际工作方式。新插件包括：

  • 人力资源：支持员工生命周期中的人员运营，从起草录用通知书和构建入职计划到撰写绩效评估和进行薪酬分析。
  • 设计：通过生成批评框架、起草 UX 文案、运行可访问性审计和构建用户研究计划来加速设计工作流程。
  • 工程：简化日常工程工作流程，如撰写站立会议摘要、协调事件响应、构建部署检查清单和起草事后分析。
  • 运营：管理核心业务运营，包括流程文档、供应商评估、变更请求跟踪和手册创建。
  • 品牌声音（由 Tribe AI 提供）：分析您现有的文档、营销材料和对话，以将您的品牌声音提炼成清晰、可执行的指南。
  • 财务分析：支持每位财务分析师所需的基本工作流程，从市场和竞争研究到财务建模以及 PowerPoint 模板创建和质量检查。
  • 投资银行：加速交易工作流程，包括审查交易文件、构建可比公司分析和准备宣传材料。
  • 股票研究：简化研究工作流程，如解析收益记录、使用新指引更新财务模型以及起草研究笔记。
  • 私募股权：通过审查大量文件集、提取标准化财务数据、建模情景以及根据投资标准对机会进行评分来支持交易寻找和尽职调查。
  • 财富管理：帮助顾问大规模分析投资组合、识别偏差和税务敞口，并生成再平衡建议。

插件是您拥有的简单、可移植的文件系统。它们适用于 Cowork 和基于 Claude Agent SDK 构建的任何内容，使跨团队和行业专家创建私有插件市场变得容易。

“三股浪潮重塑了专业工作：生产力工具、云和搜索，以及现在的代理式 AI。普华永道正在与 Anthropic 合作，将企业级代理引入 CFO 办公室——通过为每个团队成员提供工具以进行更雄心勃勃的工作、做出更好的决策并以以前不可能的方式发展业务，使财务团队成为更具战略性和价值的职能。” - 普华永道 Anthropic 联盟负责人 Sanjay Subramanian
“两年来，市场一直在向我们宣传AI代理，称它们会像数字员工一样，围绕特定、离散的工作流程全天候工作。Anthropic构建的产品要好得多。”——Mark Hines，Blank Metal首席运营官

跨应用工作

Claude现在还可以在Excel和PowerPoint中端到端处理多步骤任务。Claude可以使用并在Office插件之间传递上下文，这使其能够承担更大的项目，比如在Excel中进行分析，然后在PowerPoint中制作演示文稿。这是一个早期研究预览，表明Claude可以像我们一样跨应用工作。

开始使用

所有插件的用户体验更新对所有Cowork用户开放。团队和企业管理员可以访问公司品牌、配置和MCP控制。

Claude跨Excel和PowerPoint的工作现已在研究预览版中向Mac和Windows上的所有付费计划提供。下载插件Claude in Excel 和 Claude in PowerPoint 即可开始使用。

要了解更多关于Cowork和金融服务插件的详情，请参阅我们的配套博客文章。
