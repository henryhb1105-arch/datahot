# 为你：从有效阅读到具体问题推荐

入口为「为你」，不需要先选关键词、登录或新增账户。目标是让用户更快找到能接着当前研究问题阅读的材料。2026-10-18 的本轮改动替换了仅聚合 topic/vendor/product 的行为推荐，保留此前阅读计时与阅读优先布局。

## 产品方案与排序依据

- 记录真正的阅读：正文前台、窗口有焦点累计20秒且达到50%深度。误点、后台和超过60秒闲置不算。单步最多5秒，避免计时器挂起制造阅读。
- 根据读过的具体文章建立证据：使用索引中的标题与内容介绍进行本地分词、TF-IDF余弦匹配；标题权重较高、稀有词更有区分力、品牌与泛词降权。不是全文语义模型，不声称理解全部原文或人的真实意图。
- 具体问题别名只补充词汇证据：评测、指标口径、可观测性等须有实质共同词，不能单凭问题名命中。主问题来自标题，避免正文顺带谈成本就推成本；业务指标根因不等于基础设施可观测性。获奖/融资公告不因厂商一致替代工作实践。
- 不使用文章分类标签产生行为兴趣；明确选择的工作、主题、厂商仍可拓宽候选。已有内容证据时降低公共热度和泛标签的排序影响。质量、新鲜度、来源仍参与排序。
- 有效阅读权重2，14天减半；收藏/有用各6，强信号上限6。当前目录找不到的历史文章不猜测其内容。行为匹配加分最多85；相似负反馈降分。没有可信内容匹配且无主动偏好时回到公共精选，保留兴趣外发现，避免空白或强凑推荐。
- 「为你挑选」允许相关旧参考进入前三，显示原文日期；新变化仍单列，不把旧材料伪装成新闻。已有效阅读的文章移出未读。推荐理由明确「接着你读过的《文章》·共同讨论：具体问题/词汇」。
- 「不感兴趣」隐藏文章并减少相似内容；「少推相似内容」抑制内容邻近文章，不取消主动关注、不屏蔽整个泛分类；可撤销。「质量不好」等非兴趣反馈不扩散成兴趣否定。历史版本的明确减少分类设置继续尊重。

## 隐私与控制

全部在当前浏览器运行，无阅读历史上传、无外部模型API、无新增付费服务。持久存储仅文章ID、时间与控制设置，不存正文/搜索词/完整URL。同一文章每天按UTC最多一次，最多保留3个日期；总计200篇/90天。计算取权重最高40个正信号、至多40个负信号，限制同步计算量，完整历史仍按原期限保留。

「推荐设置 → 浏览行为推荐」可暂停记录和行为推荐；清除阅读记录同时清除减少偏好，收藏/反馈/主动关注/手动已读独立保留。暂停后清除不重启学习，跨标签页变化生效，存储失败不冒称保存。换浏览器或设备不自动同步。

## 可重复验收与边界

真实公开文章样本保存在 tests/fixtures/reading-intents.json：读Cortex评测与语义上下文配对评测，应找出ClickHouse基准/Spotter BIRD；读指标口径与治理，应找出DataJunction/口径分裂/定义实践；读Netflix可观测性，应找出Shopify可观测性而非业务根因或指标语义层。同标签不同需求、跨标签同问题、品牌公告反例、负反馈/撤销与暂停过期都有断言。样本是有限回归集，不是总体准确率或用户收益指标。

Linux Chromium实际读两篇正文产生记录，再返回「为你」检查推荐、来源依据、首篇位置、日期、暂停清除、减少撤销与资产哈希。另在临时浏览器注入一组指标阅读历史作对照，不伪造成真实用户行为；390px/1440px截图实际审阅。线上核对release SHA、全部详情和交互，排除统计，不写生产数据。

局限：内容介绍缺失/错误、同义表达未覆盖、读文章为反驳而非认可仍可能误判。不能承诺一次阅读就精确理解需求。用户可用收藏/有用、减少、暂停和清除纠偏；以后新增模型应先有独立评测与隐私/成本授权，不在这轮偷偷调用。
