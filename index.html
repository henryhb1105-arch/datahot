Databricks AI Runtime GA：用企业数据定制开源模型

Databricks 宣布 AI Runtime（AIR）正式可用，将全托管 GPU 基础设施直接引入 Databricks，使客户能在企业数据所在处训练复杂模型。AIR 旨在减少 GPU 容量管理、故障处理和实验等待，并避免独立 GPU 栈带来的治理缺口与训练数据风险。它提供 Serverless 按需 GPU、多节点训练、秒级启动延迟、环境缓存与调试工具，并已支撑 10 万+ GPU 小时训练运行。AIR 运行在 Databricks 与 Unity Catalog 的治理边界内，支持访问策略、审计和敏感训练数据保护；Robinhood、PicPay、Merck、Flo Health、TinyFish、FactSet 等客户已在使用。

为什么值得关注

该发布把 GPU 训练基础设施纳入 Lakehouse 与 Unity Catalog 治理体系，直接影响数据平台上的 AI 训练、权限治理和成本性能权衡，数据从业者应关注。

Metabase 用 GROUPING SETS 加速透视表

Metabase 64 对透视表进行了重大升级：此前计算行、列和总计会向数据库发送多条查询，两个分组字段可能跑 4 条查询，五个字段最多可达 32 条。新实现利用多数现代数仓支持的 SQL GROUPING SETS，将整个透视表合并为单条查询。官方基准中通常快 2–3 倍，并保证明细与总计一致；文章还讨论了行数上限保护和不同 SQL 方言的兼容问题。

为什么值得关注
