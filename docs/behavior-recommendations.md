# 为你：本地行为推荐第一版

目标：减少用户反复填写兴趣和从公共热榜中寻找相关内容的成本。入口仍为「为你」，跳过兴趣设置也可以随阅读形成推荐。此功能在当前浏览器计算，不需要登录，不上传阅读历史，不调用模型。

## 信号与限制

- 正文在前台且窗口获得焦点，累计阅读至少20秒、达到正文50%深度，才记录有效阅读。单个计时步最多5秒，后台和超过60秒没有交互的闲置时间不计；误点和只看标题不计。
- 同一文章每天（UTC日期）最多记录一次，最多保留最近3个阅读日期；不同日重访增加信号。最多200篇，90天过期，阅读权重每14天减半。
- 有效阅读权重2，收藏/有用反馈各6；同维度达到3才参与行为推荐，单次误判不会立即创建兴趣。标签仅使用现有主题、厂商、产品，不保存正文、搜索词或完整访问URL。
- 个人明确选择继续有效；行为可补充其范围。行为加分最多24，保留全站质量/新鲜度与明确偏好。没有信号时仍展示公共精选。
- 已有效阅读的文章移出未读重点；可标为未读（同时忘记该条阅读信号）。「不感兴趣」优先隐藏；「减少此类」只抑制该维度的行为推荐，不取消主动关注，可撤销。
- 推荐理由区分主动选择、近期阅读、收藏和有用反馈。仍保留最多2条兴趣外探索。

## 用户控制

「用浏览行为改善推荐」可暂停记录及行为推荐；「清除阅读记录」删除阅读和减少偏好，保留收藏、反馈、主动关注及手动已读。暂停后清除仍保持暂停。跨标签页变化生效；存储不可用时不声称保存成功。详情页告知本地学习并提供设置入口。隐私页说明保存期限。没有账号同步，不承诺算法精确理解兴趣。
