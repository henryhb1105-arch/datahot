# 移动端 UI 一致性与适配 · Issue 268

用户本轮不需要周报工作，优先 UI/UX 一致性及 iPhone 等设备适配。

## 读者问题与改变

- 搜索框分别使用胶囊、方框、13px 等样式。统一 10px 圆角、边线、焦点环；移动输入和选择文本为 16px，保留用户缩放。
- 收藏筛选、案例筛选、为你操作的点击区域不同。移动操作最小高度 44px，为你收藏最小宽度 44px；选中状态使用相同青绿色体系。
- 收藏项目栏在小屏上把选择器与导出按钮挤在一行。改成上下排列，保持清楚的选择和动作顺序。
- 各主要页面的标题、左右留白不齐。手机统一标题尺度与 16px 基础留白，横屏留白同时服从设备安全区。
- 底部导航到 1199px 仍存在，但提示/对比栏只在 600px 以下避让。统一避让断点；844px 横屏对比栏底部 322px，导航顶部约 328px。
- 更多菜单只允许 70vh，横屏末排被截。按动态视口上限布局，内部滚动；更多/设置的关闭入口保持可用。分享面板同步安全区和动态高度。

## 验收

- Chrome 浏览器视口 320×568、390×844、430×932、844×390、768×1024、1440×900；热榜/为你/案例/收藏/主题共 30 组页面没有横向溢出。
- 手机搜索、选择控件实际计算字号 16px；案例搜索 Metabase 可返回 1 条。
- 844×390：案例对比栏在底部导航上方；更多菜单全部六个入口可见；推荐设置的完成按钮可见且可关闭。
- 320px 文章详情标题、操作栏、正文无横向溢出。默认展开的关注理由保留。
- 本地 Python 582 项通过（3 项依赖 gitleaks 的测试跳过，CI 执行完整检查）；Node 102 项通过。
- 正式发布状态与线上证据记录在 Issue 268。

本轮是浏览器响应式检查，未声称已在实体 iPhone Safari 或 Surface Duo 真机验收；安全区和键盘行为仍需真机观察。
