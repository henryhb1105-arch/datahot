Databricks 宣布 Unity Catalog 的 Workday Data Connect 联邦连接器进入公开 Beta，面向需要将 Workday HR 与财务数据同其他企业数据一起分析的数据平台与分析团队。通过 Lakehouse Federation，团队可直接从 Databricks Data + AI Platform 查询 Workday Data Cloud 中的 HR 和财务数据，而无需维护重复副本。管理员可在 Workday 侧共享表并授权 Integration System User 只读访问，在 Databricks 创建 OAuth 连接与 Unity Catalog 外部目录，再通过表级访问控制治理权限。用户可用 Databricks SQL、AI/BI、notebooks 和 Genie 查询该目录。
