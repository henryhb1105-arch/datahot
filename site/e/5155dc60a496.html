Armature 是一款面向 MCP 的 Agent 会话产品分析与评测工具，正在 Hacker News 上以 Show HN 形式展示，获得 42 赞和 8 条评论。它的核心定位是：用户与产品的交互发生在 Claude、ChatGPT、Claude Code 等 AI 客户端内部，而不是你的 UI 中；Armature 能展示用户用你的产品做了什么，并通过评测（evals）确保产品持续可用。

该工具提供 MCP Analytics 和 MCP & CLI Evals 两类能力：前者查看用户行为，后者对用户工作流运行评测。在 Armature 之前，开发者只有零散的工具调用日志；接入后，会话被重建，用户意图、Agent 思考过程被捕捉，会话得到评估。示例会话显示：用户意图是“为 ACME 设置付费方案并给他们开票”，Agent 思考“发票需要结算联系人——用所有者邮箱重试”，最终成功完成，得分 92。

在用例分析上，Armature 的模型会读取每个会话，识别用户想完成的任务，按事件量和成功率分组排序，包括尚未支持的用况。示例数据中：创建并发送发票占 38%，对账占 22%，批量退款尚未支持占 14%，导出营收报告占 9%。

在问题发现上，模型会扫描每个会话中的失败、循环和死胡同，按根因分组，并按遇到问题的用户数排序，即使所有 API 响应都是 200 OK 也能发现异常。示例问题包括：127 次 Agent 因缺少 auth scope 而循环（本周增加 43 次）、64 次搜索未命中“refund”措辞、31 次导出被分页截断、12 次批量更新触发限流。

会话回放功能为每个会话评估用户是否达成了目标。开发者可以打开任意会话，回放完整轨迹：用户的请求、Agent 的思考和工具调用。这有助于产品团队理解用户的实际使用模式，优先修复高频失败，并规划对尚未支持用况的支持。
