通过 REGISTER/UNREGISTER API 防止目录锁定

随着组织采用湖仓架构，数据正从专有数据仓库迁移到开放存储和表格式，使 Spark、Trino 等引擎无需复制即可访问。开放格式只是一部分，真正开放还需要目录之间的互操作性与灵活治理。REGISTER 端点可将已有表挂载到任意 IRC 目录；UNREGISTER 端点被加入 Apache Iceberg REST 目录规范，让旧目录忘记该表并返回指针，避免 DROP 清理底层数据与元数据。这样可在不重写、导出或复制文件的情况下在目录间迁移表。

推荐理由：目录锁定是湖仓选型的关键风险；文章解释 Iceberg REST 目录 REGISTER/UNREGISTER 机制，帮助数据平台团队评估跨引擎、跨目录可移植性。
