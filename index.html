AWS 为 Lambda 增加 GPU 支持，Event Functions 可运行在 Lambda Managed Instances 的 EC2 G 系列实例（G4dn/G5/G6/G6f/Gr6/Gr6f/G6e）上，以容器镜像部署并复用既有事件源。单个 GPU 上最多 48 个并发调用共享一个模型，提供 vLLM 与 SGLang 基础镜像且无需编写 handler 代码，异步超时提升至 90 分钟。计费为 EC2 按需价格加 9.75% 管理费，另加每百万请求 0.20 美元。早期实测显示发布耗时约 8 分钟，且暂不支持响应流式输出。

为什么值得关注

把无服务器的事件驱动弹性与 GPU 推理结合，直接关系到数据团队低成本部署 Text-to-SQL 与嵌入模型的方式，其并发共享、冷启动与流式缺失等边界值得评估。
