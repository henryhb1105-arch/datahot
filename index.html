Kinesis推出Streaming Tables：实时数据入湖Iceberg

Amazon Kinesis Data Streams 推出 Streaming Tables，可将流式数据持续投递为 S3 Tables 上的 Apache Iceberg 表，并自动注册到 Glue Data Catalog，供 Athena、Redshift、Spark 等查询。相比自建方案，数据投递成本降低最多50%，下游查询成本降低最多30%，通过智能内联压缩消除小文件问题。该能力无需自定义应用或自管算力，也可将数据以源格式投递至 S3 通用桶，用于归档、备份和机器学习训练。

推荐理由：流式数据入湖是实时分析与AI特征管道的关键路径，该托管能力降低了运维复杂度和成本，数据工程师应关注。
