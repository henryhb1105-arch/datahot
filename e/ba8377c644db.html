更新： 我们已将Agent Skills 作为跨平台可移植性的开放标准发布。（2025年12月18日） 自从推出Skills以来，我们从客户那里听到的两个最大的问题是：“技能和MCP如何协同工作？什么时候应该使用其中一个而不是另一个？”

Model Context Protocol (MCP) 将Claude连接到第三方工具，技能则教会Claude如何妥善使用这些工具。当您将两者结合时，您可以构建遵循您团队工作流程的智能体，而不是需要不断纠正的通用流程。

例如，与Notion的MCP连接让Claude能够搜索您的工作区。添加一个会议准备技能，Claude就知道该从哪些页面提取信息，如何格式化准备文档，以及什么是您团队交付会议记录的标准。连接变得有用而不仅仅是可用。

在本文中，我们剖析技能和MCP之间的关系，如何组合它们以构建遵循您工作流程的智能体，从而产生一致的输出，并逐步介绍一些实际示例，展示它们在实践中如何协同工作。

理解技能和MCP

您走进一家五金店，想要修理一个损坏的橱柜。商店里有您所需的一切（木胶、夹钳、替换铰链），但知道要购买哪些物品以及如何使用它们则是另一个问题。

MCP就像能够进入过道。技能则像员工的专业知识。如果您不知道需要哪些物品或如何使用它们，世界上所有的库存也无济于事。技能就像一位乐于助人的员工，带您完成修复过程，向您指出正确的用品，并展示正确的技术。

更具体地说，MCP服务器让Claude能够访问您的外部系统、服务和平台，而技能则提供Claude有效使用这些连接所需的上下文，教Claude在拥有访问权限后该做什么。没有技能提供的上下文，Claude只能猜测您想要什么。有了技能，Claude就能遵循您的剧本。

为什么技能和MCP能很好地协同工作

MCP处理连接性：安全、标准化地访问外部系统。无论您是要连接到GitHub、Salesforce、Notion，还是您自己的内部API，MCP服务器都能让Claude访问您的工具和数据。

技能处理专业知识：将原始工具访问转化为可靠结果的领域知识和工作流程逻辑。技能知道何时查询您的CRM、在结果中寻找什么、如何格式化输出，以及哪些边缘情况需要不同处理。这种分离保持了架构的可组合性。单个技能可以编排多个MCP服务器，而单个MCP服务器可以支持数十种不同的技能。添加新连接，现有技能就能将其纳入。完善技能，它就能在所有连接的工具上工作。

当您结合技能和MCP时，您会得到：

清晰的发现：Claude不再猜测去哪里查找。会议准备技能可能会指定：先检查项目页面，然后是之前的会议记录，再是利益相关者资料。研究技能可能会说：从共享驱动器开始，与CRM交叉引用，然后用网络搜索填补空白。技能编码了关于哪些来源对哪些任务重要的机构知识。

可靠的编排：多步骤工作流程变得可预测。没有技能，Claude可能会先提取数据并格式化，然后才检查是否拥有一切。技能明确界定了顺序，因此Claude每次都执行相同的工作流程。

一致的性能：输出实际上符合标准。通用结果需要编辑。技能为您的团队定义了“完成”的样子：正确的结构、正确的详细程度、适合受众的语气。

随着时间的推移，团队会构建起相互关联的技能和连接的集合，为Claude提供特定领域的专业知识。

技能和MCP可能重叠的地方‍

MCP服务器可能包含工具使用提示和常见任务提示形式的说明。这使特定于工具的知识靠近工具。然而，这些说明应设计为保持通用。

经验法则：MCP说明涵盖如何正确使用服务器及其工具。技能说明涵盖如何在给定流程或多服务器工作流程中使用它们。

例如，Salesforce MCP服务器可能会指定查询语法和API格式。技能则会指定首先检查哪些记录，如何与Slack对话交叉引用以获取最新上下文，以及如何为您的团队管道审查构建输出。当组合MCP服务器和技能时，请注意冲突的指令。如果您的MCP服务器说要返回JSON，而您的技能说要格式化为markdown表格，Claude就必须猜测哪个是正确的。让MCP处理连接性，让技能处理呈现、排序和工作流程逻辑。

进一步阅读： 了解技能如何使用渐进式披露按需加载上下文，以及程序化工具调用高效编排MCP工具。

实际示例：技能和MCP结合使用

现在让我们看看技能和MCP在实际工作流程中如何组合。我们将介绍两个示例：财务分析师获取实时市场数据进行公司估值，以及项目经理使用Notion的会议智能技能进行会议准备。

在两种情况下，MCP服务器提供对工具的访问，技能定义如何处理它们。

财务分析：自动化公司估值技能

Anthropic 发布了一组预构建的技能，用于常见的财务工作流程，包括可比公司分析。可比公司分析是一种标准的估值方法。进行可比公司分析的分析师会花费数小时从多个来源提取财务指标，应用相同的估值方法，并格式化输出以符合合规标准。这是重复性的、容易出错的，并且正是那种受益于技能和 MCP 协同工作的流程。

技能：可比公司分析自动化此估值流程，从多个来源提取数据，应用一致的方法，并将输出格式化为特定标准。

MCP 服务器：连接到 S&P Capital IQ、Daloopa 和 Morningstar 以获取实时市场数据

工作流程：

  1. 技能识别要查询的数据源（发现）
  2. MCP 连接获取实时财务数据
  3. 技能应用方法并格式化输出（编排）
  4. 技能根据合规要求进行验证（性能）

会议准备：Notion 的会议智能技能

会议准备很乏味。您需要从多个地方获取上下文，例如项目文档、以前的会议记录和利益相关者信息，然后将其综合成预读材料和议程。这是那种每次都需要重新解释的多步骤过程。

技能：会议智能定义要搜索的页面、如何构建输出、要包含哪些部分

MCP 服务器：搜索、读取和创建页面的 Notion 连接

工作流程：

  1. 技能识别要搜索的相关页面，包括项目、以前的会议、利益相关者信息（发现）
  2. MCP 连接搜索并从 Notion 检索内容
  3. 技能构建两个文档：内部预读材料和外部议程（编排）
  4. MCP 连接将两个文档保存到 Notion，组织并链接
  5. 技能确保输出符合格式标准（性能）

何时使用技能与 MCP

‍技能和 MCP 解决不同的问题，但决定对特定工作流程使用哪个并不总是显而易见的。

技能用于什么

技能捕获原本存在于您头脑中的知识，或者每次新团队成员加入时都需要重新解释的知识。它们最适合：

  • 涉及工具的多步骤工作流程：从多个来源提取信息，然后创建结构化文档的会议准备
  • 需要一致性的流程：必须每次都遵循相同方法的季度财务分析，具有强制检查点的合规审查
  • 您希望捕获和分享的专业知识：研究方法论、代码审查标准、写作指南
  • 团队成员离开时应该保留的工作流程：编码为可重用指令的制度知识

MCP 服务器用于什么

MCP 扩展了 Claude 可以访问和使用的内容。当您需要以下内容时使用 MCP：

  • 实时数据访问：搜索 Notion 页面、阅读 Slack 消息、查询数据库
  • 在外部系统中的操作：创建 GitHub 问题、更新项目管理工具、发送通知
  • 文件操作：读写 Google Drive、访问本地文件系统
  • API 集成：连接到没有原生 Claude 支持的服务

如果您在解释如何做某事，那就是技能。如果您需要 Claude访问某些东西，那就是 MCP。

常见问题

技能会取代 MCP 吗？

不会。技能和 MCP 解决不同的问题。MCP 提供与外部工具和数据的连接。技能提供如何有效使用该连接的程序性知识。最强大的工作流程会同时使用两者。

一个技能可以使用多个 MCP 服务器吗？

可以。一个技能可以同时协调多个 MCP 服务器。一个技术竞争分析技能可能搜索 Google Drive 获取内部研究，从 GitHub 拉取竞争对手的仓库，并通过网络搜索收集市场数据。

我可以为一个 MCP 服务器构建多个技能吗？

可以。一个技能可以增强从单个 MCP 连接中获取的价值。Notion 通过为会议准备、研究、知识捕获和规范到实施提供单独的技能来演示这种模式——请查看它们此处。
