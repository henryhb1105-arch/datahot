Meta广告MCP服务器上线Databricks，接入Genie

Databricks Marketplace 现已上架 Meta 的广告 MCP 服务器，企业可将其连接到 Genie，用自然语言同时探索 Meta 广告表现与 Databricks 中受治理的业务数据。该 MCP 服务器暴露 25+ 个覆盖活动生命周期的工具，包括创建活动/广告组、调整预算与出价、定义受众、管理创意与目录、拉取表现数据和诊断信号质量。这延续了双方此前的合作：Meta Conversions API 已登陆 Databricks Marketplace，用于发送第一方转化信号。目标是减少 CSV 导出和自维护 Marketing API 集成，让 churn 分数、LTV、归因和 margin 表等洞察更直接进入广告投放决策。

推荐理由：数据从业者应关注Databricks如何通过MCP把外部广告平台工具接入Genie，使受治理指标、业务模型与营销执行在同一对话中联动，代表数据平台与AI Agent接口融合的新方向。
