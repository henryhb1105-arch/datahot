# 为你：打开即阅读

2026-10-18，Issue #204。Henry 的真实反馈：进入「为你」后很久才看到第一篇文章；本次解决阅读入口，不把前两次推荐功能算作新增。

## 证据和选择

Linux Chromium 154，390×900 / 1440×900，线上干净浏览器，排除统计：

| 状态 | 手机首篇距页面顶部 | 桌面首篇距页面顶部 |
| --- | ---: | ---: |
| 首次访问 | 1006.78px | 914.11px |
| 跳过设置后返回 | 540.44px | 547.34px |

标题区还被全站 header 样式设为 sticky，手机占211px、桌面205px。用户阅读时仍要绕过它。首次设置卡、默认首页和阅读行为说明依次位于文章之前。

候选：缩小间距只能治表；改推荐算法不解决内容可达性；因此选择重排信息层级。

## 产品改变

- 首次和再次进入都直接展示文章，不前置问卷或设置。新用户读完三条精选后可继续发现更多文章，不再遇到必须设置才能继续的断点；空的已读区不显示。
- 紧凑标题取消吸顶；保留明确「为你」定位和一个「推荐设置」入口。
- 兴趣、默认首页、行为推荐及阅读记录清除归入同一按需打开的设置面板。手机底部面板，桌面对话框；即时保存，关闭回到阅读，Escape 和焦点返回可用。
- 访问时间/未读数放到对应的新变化区域；产品雷达/实施参考放到设置的发现链接，避免入口挤占首屏。
- 详情隐私链接仍可直接打开并定位到行为开关。关闭面板移除已消费的隐私 hash，返回文章列表不会意外重复打开。
- 每篇推荐理由和「为什么重要」仍默认展开。既有浏览行为学习、主动兴趣、收藏、已读及首页偏好保留，不迁移或清空用户数据。

## 验收

`tests/for-you-browser.cjs` 在390/1440宽度验证首次文章top<200px、理由首屏可读、实际CSS非sticky、设置打开关闭/Escape/焦点、工作与关注保存、首页切换、隐私深链及阅读返回，并输出截图供人工审阅。`tests/reading-browser.cjs`继续真实20秒有效阅读、推荐变化、暂停/清除等回归。

运行 `CHROME_PATH=/usr/bin/chromium node tests/cloud-acceptance.cjs`；生产使用固定正式源和准确release SHA，详见docs/cloud-migration.md。实际前后截图及发布/线上结果记录Issue，不能仅用静态测试或Actions成功代替。
