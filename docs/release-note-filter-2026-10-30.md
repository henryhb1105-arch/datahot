# Release note 列表过滤 · Issue 262

Henry 要求过滤部分 release note 类文章。本次把文档类型与信息质量分开处理：版本日志即使含有准确的技术细节，也不自动成为资讯推荐。

## 边界

- 识别明确的 release notes / changelog 信源、文档路径和版本说明标题。
- 优先依据实际选中的正文来源；聚合事件只要引用一个发布日志，不会因此误伤选中的工程文章。
- 来源不明时只使用明确的版本说明标题或全部来源的一致证据，不按“发布”“预览”“release”几个词粗暴过滤。
- 人工编辑的阅读笔记保留。正文未核验仍由独立规则处理，不把抓取失败标成低信息量。
- 规则通过共享列表门禁作用于首页、热榜、搜索、主题、为你、关联文章、Atom 和 Agent Feed。未来新增数据每次构建也经过同一规则。
- 原始记录、详情 URL 与用户收藏保留；不修改采集数据。`LOW_INFORMATION_FILTER_ENABLED=false` 可以回滚列表过滤。
