Anthropic如何使用Claude进行营销：广告制作从30分钟缩短至30秒

DataHot 速览

Anthropic增长营销团队成员Austin Lau原本完全没有编程经验，但在同事指导下使用Claude Code构建了两个关键工作流：一个Figma插件可一键生成广告创意变体，另一个Google Ads文案工作流可帮助头脑风暴并导出为CSV文件。过去每条广告需要30分钟，现在仅需30秒。该实践展示了非技术营销人员如何利用AI工具大幅提升广告内容生产效率。

为什么值得关注：展示了非技术营销人员通过Claude Code实现广告素材自动化生成的实际案例，对数据Agent在营销场景的应用有参考价值，可作为AI Agent辅助具体业务工作的实证。

Anthropic 营销增长团队如何借助 Claude Code 将广告创建时间从 30 分钟缩短至 30 秒

Anthropic 的营销增长专员 Austin Lau 分享了他是如何从一个从未打开过终端的人，变成能够构建 Figma 插件和自动化广告生成工作流，而无需编写一行代码。

  • 类别企业 AI
  • 产品Claude Enterprise
  • 日期 2026 年 1 月 26 日
  • 阅读时间 5 分钟
  • 分享复制链接https://claude.com/blog/how-anthropic-uses-claude-marketing

在接触 Claude Code 之前，Austin Lau 一生中从未写过一行代码。当产品首次发布时，他不得不去谷歌搜索如何在电脑上打开终端。

“当我们推出 Claude Code 时，我的第一反应是，我完全不知道这个产品是干什么的，”Anthropic 的营销增长专员 Austin 说。“作为一名营销人员，它并没有真正引起我的共鸣——当时我还不清楚它的用例。”

但好奇心占了上风。

Anthropic 的一位同事在公司 Slack 工作区发布了一份指南，介绍非技术员工如何安装 Claude Code。Austin 决定按照指南操作。

一周后，Austin 构建了两个工作流，从根本上改变了他的工作方式：一个 Figma 插件，可一键生成广告创意变体；以及一个 Google Ads 文案工作流，帮助他头脑风暴和优化广告文案，然后导出为可直接上传的 CSV 文件。以前每条广告需要 30 分钟，现在只需 30 秒。

以下是他如何做到的，以及营销人员可以从他使用 Claude Code 的经验中学到什么。

‍

问题：被文案和创意变体淹没

大规模开展效果营销需要不断产出新鲜创意。谷歌的响应式搜索广告仅标题就需要 15 个独特的变体。每隔几周，这些文案就需要更新——同时还要保持品牌语调并传达价值主张。

“这方面具有挑战性的是，当你在这种水平上运营时，你需要非常非常频繁地刷新文案，”Austin 解释说。“而且谷歌的文案要求由于严格的字符数限制而灵活性较低。”

旧流程是这样的：打开 Google Sheets，头脑风暴标题和描述，手动检查字符数，复制粘贴到 Google Ads，然后重复。

对于视觉广告，流程更加复杂。Austin 会打开 Figma，多次复制现有画框，切换到 Google Doc 获取标题文案，再切换回 Figma 粘贴文案，重复操作——涵盖十多个变体和多种宽高比。

“所有这些时间加起来非常非常快，”Austin 说。

解决方案：消除营销繁琐工作的两个工作流

使用 Claude，Austin 最终构建了两个改变他日常生活的流程。但 Austin 的第一个项目是构建一个简单的计算器应用。

“我实际上让 Claude 做的第一件事是给我做一个非常简单的计算器应用，只是为了看看它会如何回应，”他回忆道。“Claude 基本上为我创建了后端，以及一个简单的前端。然后它基本上告诉我‘这是你实际运行它的方式’。”

那个小实验改变了他对自己在工作任务中能取得什么成就的看法。

用于创意变体的 Figma 插件

创建广告变体意味着无尽的复制、粘贴以及在 Figma 和 Google Docs 之间切换。

于是 Austin 用 Claude Code 构建了一个 Figma 插件，这个项目花了大约 45 分钟到 1 小时来构建，但现在每次他跨多种宽高比更新一大批创意时，能为他节省近 30 分钟。

首先，他打开 Claude Code，通过提示描述了他的问题：“Claude，我在 Figma 中工作。我非常想解决这种重复复制粘贴的挑战。你能帮我构建一个 Figma 插件来解决我的挑战吗？”

Claude 出去做了研究，评估如何最好地构建插件，有哪些限制，然后开始制作原型。经过一些故障排除后，Austin 在 Figma 中安装了一个可用的插件。

“我所要做的就是指定创意的画框，然后一次性复制粘贴所有我想要更新的不同变体和文案，点击一个按钮，Figma 插件就会为那张图片创建所有不同的排列组合，”Austin 解释道。

Google Ads 文案生成

对于响应式搜索广告，Austin 构建了一个工作流，帮助头脑风暴和创建可直接上传的广告文案，利用现有的广告系列和广告效果数据来帮助了解哪些类型的信息能引起潜在客户的共鸣。这个工作流每周节省了数小时的文案创建和字符验证时间。由于在机械性任务上节省了时间，Austin 现在可以运行更多的文案实验，并更快地迭代真正表现最佳的内容。

刚开始时，他输入/rsa，这是他专门为响应式搜索广告创建的自定义斜杠命令，输入到 Claude 中。Claude Code 会询问广告系列数据、现有文案和关键词，然后将他输入的内容与他创建的用于 Anthropic 品牌语调、产品准确性以及 Google Ads RSA 最佳实践的“代理技能”进行交叉参考。代理技能但他创建的用于 Anthropic 品牌语调、产品准确性以及 Google Ads RSA 最佳实践的“代理技能”。

但输出只是一个起点。

“Claude 是一个很棒的头脑风暴伙伴，但有时它不能一次就做对，”Austin 解释说。“我所做的很多工作就是反复推敲，来回修改，以帮助逐步完善文案。”

这种修改很重要，因为 Austin 会根据他所了解的能引起 Anthropic 受众共鸣的内容来评估每个标题。价值主张是否明确？语调是否正确？是否能在竞争对手中脱颖而出？一旦文案合适，Claude Code 会将所有内容合并成一个可上传的 CSV 文件。

而这一切都建立在人的基础之上。奥斯汀说：“我们提供给Claude的所有文案和示例，都是与产品营销和文案团队合作撰写的。”这个坚实的起点意味着，在Claude开始头脑风暴之前，就已经融入了人的判断。

构建自己的工作流程的最佳实践

奥斯汀的经验为营销人员——或者说任何没有技术背景的人——提供了实用指导，帮助大家使用Claude Code构建自定义工具。

从小处着手，从重复性步骤开始

奥斯汀解释说：“我的建议是：如果你想尝试像Claude Code这样的工具，就想一想你工作中哪些部分是你已经确定重复的，或者你认为可以自动化的，然后从一个非常、非常小且容易的事情开始。”

例如，奥斯汀的第一个项目是构建他的计算器应用，先看看Claude是如何工作的。

让好奇心驱动你的工作

奥斯汀形容自己是“那种如果对某件事非常好奇，就会变得几乎固执，必须找到答案的人。”正是这种坚持，让他把一开始不知道怎么交互的空白终端，变成了他每天使用的实用工具。

像向同事解释问题一样与Claude交流

奥斯汀说：“你不需要知道如何编程。你只需要知道如何清晰、简洁地解释你的挑战和你试图解决的问题。”

非技术员工已经在自己领域内是专家。他们了解自己的工作流程，感受到痛点，并且确切知道他们需要什么样的输出。Claude Code让他们能够自己修复任何重复出现的技术问题。

利用现有资源

对于Figma插件，奥斯汀让Claude Code参考了已有的Figma API文档。利用现有文档，Claude进行了自己的研究，并构建了一个原型供奥斯汀实验。一个勉强能用的原型就足以证明奥斯汀心中的概念，最终发展成了一个可用的产品。

更广阔的图景

在奥斯汀的职业生涯中，他曾经认为某些事情是遥不可及的。如果他需要安装跟踪像素，他必须请工程师来安装。如果他需要构建自定义工作流程，他必须向支持部门提交工单。

奥斯汀说：“可以说几年前，如果你有一个想法要构建这样的工作流程，你可能需要一个工程师团队来支持你。现在，有了像Claude Code这样的工具，作为一个非技术营销人员，我实际上可以自己去构建这些东西。所以，‘我希望这个存在’和‘我可以自己构建它’之间的差距，实际上比人们意识到的要小得多。”

他现在已经向同事和客户演示了他的工作流程，他们的反应都一样：为什么我们没有这样做？

营销人员的下一步是什么

奥斯汀认为增长营销人员的角色正在迅速演变。奥斯汀说：“我认为增长营销正朝着类似产品经理的方向发展。我们不仅能够执行营销活动，还能够构建产品来帮助我们实现目标。”

奥斯汀并不是Anthropic唯一一个使用Claude构建工具的营销人员。在整个营销组织中，各个团队都发现了类似的结果：

  • 网红营销 使用Claude为网红和播客写脚本，每月节省了100多个小时，用于更高价值的工作
  • 客户营销 在30分钟内起草案例研究，而不是2.5小时，每周节省10个小时
  • 数字营销 构建了网络开发工作流程，使团队生产力同比提高了5倍
  • 产品营销 使用技能和项目创建启动简报，每次启动节省5-10个小时
  • 合作伙伴营销 为销售团队构建了自助服务活动支持，将贸易展准备时间减少了40%

奥斯汀说：“大多数营销人员可能以同样的方式对待AI，他们只将其视为简化文案撰写或头脑风暴等事情的一种方式。但他们并没有真正思考过，哪些实际领域可以将像Claude这样的工具真正嵌入到他们的工作流程中。”

对于采用像Claude Code这样的工具的团队来说，有一个机会正在出现：花更少的时间在重复执行上，更多的时间在对自己工作重要的事情上。
